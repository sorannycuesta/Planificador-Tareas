# Planificador Personal

Aplicación web diseñada para facilitar la organización de tareas, actividades y metas personales de manera sencilla e intuitiva. Permite gestionar las actividades diarias, llevar un seguimiento de las tareas pendientes y completadas, y mantener una mejor organización del tiempo. Su objetivo es ofrecer un espacio práctico y visual que ayude a mejorar la productividad y planificar las actividades del día a día.
